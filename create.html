Create your own question set

qbank-player plays JSON question sets. The easiest way to make one is to have Claude (or another LLM) write it from your notes, lecture slides or a topic you choose.

  1. Copy the prompt below after adjusting the options.
  2. Paste it into Claude (or another LLM) in a new chat, and attach your study material if you have some.
  3. Load the JSON it produces: download the file or copy the code block, then drop or paste it in the Library.

Reference

The prompt already includes the full schema. These are handy if you write or fix sets by hand.
